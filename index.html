DATASCI 406 — Computational Methods in Statistics and Data Science

University of Michigan, Fall 2026 · Mark M. Fredrickson

One line, in R. The same line every time. No git, no GitHub account, no extra packages:

source("https://markmfredrickson.github.io/datasci406/sync.R")

First run creates a datasci406 folder and tells you where it is; open datasci406.Rproj inside it. Run the same line again whenever new material is announced and your folder is brought up to date — your my-work folder is left alone, and a course file you have edited is never overwritten (the new version lands beside it as .new).

Prefer a browser? Download the ZIP, unzip it, open datasci406.Rproj. Already a git user? Clone the repository; nothing here ever needs pushing back. Single files below work too, but exercises load data by a relative path, so they expect the folder layout around them.
