Module 1 Project: Check Your Numbers

This is the output of one complete run of the project, with a fixed random seed. Use it to see whether your own results are in the right ballpark: the same order of magnitude, the same conclusions, the same first digit or two. It is not an answer key. There is no code and no explanation here, and the exam asks about your project, not this one.

What should match, and how closely:

  • Exact values do not depend on random numbers and should match to every digit shown: \(F(20)\) in A.1, the data fraction in A.4, the estimates in C.1 and C.2, and the observed \(S^2\) in D.4.
  • Monte Carlo estimates vary from run to run. Yours should be close, and where an exact value exists your confidence interval should contain it.
  • Choices are yours. B.2 asks for two candidate envelopes, and this run picked one pair. Different candidates give different rows, and B.3 then starts from a different pilot variance. What should agree is the pattern.
